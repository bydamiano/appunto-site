Looking for the latest version…

One file, installed like any other app. On first start Appunto downloads its speech model once (about 574 MB).

Install and open

macOS

  1. Double-click the .dmg file and drag Appunto onto the Applications folder.
  2. Open Applications and double-click Appunto.
  3. The first time, macOS says it cannot verify the app (it is not signed with a paid Apple certificate yet). Click Done, then open System Settings → Privacy & Security, scroll down, click Open Anyway next to Appunto and confirm. You only do this once.

Windows

  1. Double-click the -setup.exe file.
  2. If Windows shows “Windows protected your PC”, click More info → Run anyway (the app is not code-signed yet).
  3. Follow the installer. Appunto then appears in the Start menu.

Linux

  • .deb or .rpm: double-click it and choose Install in the Software app.
  • .AppImage: right-click it → Properties → Permissions → tick Allow executing file as program, then double-click it.
